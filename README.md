VAVE-templates
==============

Examples of VAVE data and reporting templates

## Quick start

Use the `open_template.py` helper script to quickly print the contents of any
template file in this repository:

```bash
python open_template.py data_templates/db_templates/election.txt
```

Pass `--lines` to limit the number of lines shown and `--encoding` to specify a
different file encoding if necessary.
